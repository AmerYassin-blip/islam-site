# نور — تطبيق إسلامي

تطبيق ويب يعمل على الجوال (آيفون وأندرويد) من المتصفح، ويمكن إضافته إلى الشاشة الرئيسية ويعمل دون إنترنت بعد أول فتح.

## ما في التطبيق

- مواقيت الصلاة حسب الموقع مع عدّاد للصلاة القادمة
- اتجاه القبلة مع بوصلة
- المصحف كاملًا بالرسم العثماني، مع فهرس السور وعلامة القراءة
- أذكار الصباح والمساء وبعد الصلاة والنوم والاستيقاظ
- المسبحة
- التاريخ الهجري
- البحث في القرآن بنص الآية أو جزء منها
- التفسير الميسّر لكل آية، والترجمة الإنجليزية
- التلاوات الصوتية لستة قرّاء مع «أكمل الاستماع»
- آية اليوم وحديث اليوم، والأربعون النووية
- ختمة القرآن بورد يومي
- الإعدادات: العربية والإنجليزية، اللون الأخضر أو الزهري، الوضع الليلي، حجم الخط، طريقة حساب المواقيت، وقت العصر

## المصادر

كل المحتوى الديني منقول من مصادر موثوقة دون تصرّف. التفاصيل في [SOURCES.md](SOURCES.md).

## التشغيل

لا يحتاج إلى بناء. الملفات ثابتة (HTML و CSS و JavaScript) وتُنشر كما هي على GitHub Pages.

للتجربة على الحاسوب:

```
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.
